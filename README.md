# Matheus JT RetroUI Portfolio — 3 Themes

This version adds a persistent theme switcher with three visual modes:

1. **RETRO** — the current/default RetroUI-inspired dark UI.
2. **SNES** — a Super Nintendo-inspired palette and warmer purple/blue presentation.
3. **PS2** — an early-2000s PlayStation 2-inspired dark blue interface with colder metallic/blue accents.

The theme switcher is part of the header and updates the entire page through CSS custom properties. The content and layout remain identical across themes so the portfolio stays coherent.

## Run

```bash
npm install
npm run dev
```

## Important

The SNES and PS2 themes are **inspired by the consoles' visual eras and palettes**, rather than copying logos, proprietary UI screens, fonts, or artwork.

The portfolio still uses `pixel-retroui` for its core UI components.
